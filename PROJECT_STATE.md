## 4. Key Architectural & Design Decisions

1. **Thin Routes Pattern:** `src/app/` files contain only 5–10 lines re-exporting real screens from `src/screens/`. Zero business logic or layout styling in routes.
2. **Obsidian Deep-Space Instrument Aesthetic:**
   - Backgrounds: True void black (`#04050A`), deep surface (`#0B0D14`), elevated surface (`#131622`).
   - Hairline borders: `rgba(255, 255, 255, 0.08)`.
   - Core Accent: Event Horizon Amber (`#F5A623`) for depth 0 ("Me").
   - Cosmic Tiers:
     - Depth 0 (Core): `#F5A623` (Event Horizon Amber)
     - Depth 1 (Galaxy): `#818CF8` (Nebula Indigo)
     - Depth 2 (Solar System): `#38BDF8` (Stellar Sky)
     - Depth 3 (Planet): `#2DD4BF` (Orbital Teal)
     - Depth 4+ (Moon): `#94A3B8` (Lunar Silver)
   - Platform monospace font (`Menlo` on iOS, `monospace` on Android) for technical metadata and paths.
3. **Database Architecture & Migration Flow:**
   - SQLite self-referencing hierarchy (`parent_id REFERENCES nodes(id) ON DELETE CASCADE`).
   - Foreign keys enforced explicitly via `expoDb.execSync('PRAGMA foreign_keys = ON;');` immediately on connection in `src/db/client.ts`.
   - Shared `getDescendantIds()` helper powers both circular move protection in `moveNode()` and safe target filtering in `getMoveTargets()`.
4. **Zero Emoji Chrome & Pure Vector Icons (Rule 7):**
   - Bottom tab bar uses `@expo/vector-icons` (`Ionicons` `planet`, `search`, `settings`).
   - Explorer tab sets `headerShown: false` to avoid double headers and render cleanly inside `ScreenContainer`.
5. **Reactive SQLite Data Hooks (Step 7 Delivered):**
   - Race-condition safe (`cancelled` flags, monotonic search request IDs), nullable ID resilient, and stable `useCallback` refresh handles.
6. **Explorer Screen & Node Detail Route Shell (Step 8 Delivered):**
   - **Single-Screen Hierarchy Navigation:** `ExplorerScreen` holds `currentNodeId` in React state (syncing with `rootNode.id` and optional `initialNodeId` route params). Tapping folders drills down without stack pushes; tapping entries navigates to `/node/[nodeId]`.
   - **Focused Android Hardware Back Handling:** Scoped `BackHandler` inside `useFocusEffect` pops up to `currentNode.parentId` when not at root, and automatically unsubscribes on blur.
   - **FlatList & Hooks Integrity:** `key={viewMode}` cleanly switches between `numColumns={1}` (list) and `numColumns={2}` (grid) without React Native crashes. `ExplorerNodeItem` isolates per-card `useDescendantCount` hooks outside `renderItem`.
   - **Full Long-Press CRUD:** `NodeActionsModal` triggers `RenameNodeModal` (`updateNode`), `MoveNodeModal` (`getMoveTargets` + `moveNode`), or `ConfirmDialog` (`deleteNode` with nested child count warning), surfacing feedback/errors in a dark obsidian inline banner.
   - **Starter Template Onboarding:** Empty root state exposes `"Load Starter Categories"` calling `seedStarterTemplates(rootNode.id)`.
