## 4. Key Architectural & Design Decisions

1. **Thin Routes Pattern:** `src/app/` files contain only 5–10 lines re-exporting real screens from `src/screens/`. Zero business logic or layout styling in routes.
2. **Obsidian Deep-Space Instrument Aesthetic:**
   - Backgrounds: True void black (`#04050A`), deep surface (`#0B0D14`), elevated surface (`#131622`).
   - Hairline borders: `rgba(255, 255, 255, 0.08)`.
   - Core Accent: Event Horizon Amber (`#F5A623`) for depth 0 ("Me").
   - Cosmic Tiers:
     - Depth 0 (Core): `#F5A623` (Event Horizon Amber)
     - Depth 1 (Galaxy): `#818CF8` (Nebula Indigo)
     - Depth 2 (Solar System): `#38BDF8` (Stellar Sky)
     - Depth 3 (Planet): `#2DD4BF` (Orbital Teal)
     - Depth 4+ (Moon): `#94A3B8` (Lunar Silver)
   - Platform monospace font (`Menlo` on iOS, `monospace` on Android) for technical metadata and paths.
3. **Database Architecture & Migration Flow:**
   - SQLite self-referencing hierarchy (`parent_id REFERENCES nodes(id) ON DELETE CASCADE`).
   - Foreign keys enforced explicitly via `expoDb.execSync('PRAGMA foreign_keys = ON;');` immediately on connection in `src/db/client.ts`.
   - Shared `getDescendantIds()` helper powers both circular move protection in `moveNode()` and safe target filtering in `getMoveTargets()`.
4. **Zero Emoji Chrome & Pure Vector Icons (Rule 7):**
   - Bottom tab bar uses `@expo/vector-icons` (`Ionicons` `planet`, `search`, `settings`).
   - All 3 tabs (`index`, `search`, `settings`) set `headerShown: false` to prevent duplicate headers and render cleanly inside `ScreenContainer`.
5. **Streamlined Creation & Entry Detail Editor (Step 9 Delivered):**
   - **Root Level Locked to Folders:** Depth 0 (`Me`) is reserved strictly for categories/folders: `AddNodeFAB` hides the Folder/Entry switch and titles the modal `"New Category"` at root, while `repository.ts` (`createNode`, `moveNode`, `getMoveTargets`) prevents creating or moving entries directly under depth 0.
   - **Frictionless Creation (`AddNodeFAB`):** Removed the 12-icon picker grid in favor of clean type defaults (`folder-outline` / `document-text-outline`). Defaults `nodeType` to `'entry'` when `parentDepth >= 2` (`'folder'` at depth 1), wraps the modal in `KeyboardAvoidingView`, and auto-navigates newly created entries directly into `/node/${id}?edit=1`.
   - **Universal Status Presets:** Streamlined `NodeStatus` and `STATUS_PRESETS` to 4 universal states: `Planned`, `In Progress`, `Completed`, and `Dropped`.
   - **Entry vs. Folder Separation (`NodeDetailScreen`):** Entry nodes display Status (`StatusChip`), Rating (`RatingStars`), Tags (`TagsRow` with edit-mode search hint), Details (`MetadataEditor` with clean `"No details added"` view text and edit-mode example hints), and Notes & Thoughts (`Text` / multiline `TextInputField`). Folder nodes stay minimal (Title, Description, nested item count).
   - **Null-Safe Field Clearing:** Clearing `status`, `rating`, `notes`, or `description` passes explicit `null` (never `undefined`) inside `UpdateNodePatch` so SQLite cleanly clears columns on Save.
   - **Dirty Detection & Safe Navigation:** Compares draft state against persisted `node`, prompting a dark `ConfirmDialog` (`"Discard Unsaved Changes?"`) on top bar Back, breadcrumb jump, or Android hardware `BackHandler` when unsaved edits exist.
6. **Global Search & Instant Life Lists (Step 10 Delivered):**
   - **Metadata & Filtered Search (`searchNodes` + `useSearch`):** Matches across `title`, `notes`, `status`, `tags`, and `metadata` JSON, supports `nodeType` and `status` filtering, queries matching entries instantly when a status pill is selected with empty text, and exposes `refresh()` for focus sync.
   - **Keyboard-Friendly UX (`SearchScreen`):** `headerShown: false` tab bar layout inside `<ScreenContainer avoidKeyboard>`, gentle `useFocusEffect` auto-focus (skipping when browsing a status list), `keyboardShouldPersistTaps="handled"` + `keyboardDismissMode="on-drag"` on `<FlatList>`, horizontal filter pills (`All`, `Entries`, `Folders`, plus 4 statuses), and deep navigation (entry -> `/node/${id}`, folder -> Explorer tab jumped to `nodeId`).
7. **Settings & Backup System (Step 11 Delivered):**
   - **Modern SDK 58 File API + Android Fallback Chain (`src/utils/backup.ts`):** Uses `File` & `Paths.cache` from `expo-file-system` alongside `expo-sharing` and `expo-document-picker` (`['application/json', 'text/plain', '*/*']`, `copyToCacheDirectory: true`). Import file reading uses a resilient 3-stage `readBackupUriAsText()` helper (`File.text()` across raw/encoded/decoded URIs -> `readAsStringAsync()` from `expo-file-system/legacy` -> `fetch(uri).text()`) and strips any UTF-8 BOM before JSON parsing.
   - **Strict Backup Validation:** Validates `version === 1`, non-empty `nodes[]`, required node types (`id`, `title`, `'folder' | 'entry'`, non-negative integer `depth`), root parent invariants (`depth === 0` <-> `parentId === null`), and exactly 1 folder root before triggering destructive replacement confirmation.
   - **Pinned Feedback & Decluttered Overview (`SettingsScreen` + `ExplorerScreen`):** Header and feedback banner stay pinned above `<ScrollView>` so Export/Import banners remain immediately visible when scrolled down; Starter Structure card hides automatically once `stats.galaxies > 0`. `ExplorerScreen` tracks `prevRootIdRef` to snap directly to a newly restored root UUID when switching back to Explorer.
8. **Phase 1 Polish, Safe Haptics & Release Hardening (Step 12 Delivered):**
   - **Safe Tactile Haptics (`src/utils/haptics.ts`):** `hapticLight()`, `hapticMedium()`, `hapticSuccess()`, and `hapticWarning()` guard against `Platform.OS === 'web'` and catch rejected promises/unavailable hardware quietly across rating dots, Search filter pills, view mode toggles, long-press actions, node creation, saves, backups, and destructive confirmations.
   - **Settled Node Lookup & Post-Restore Recovery (`useNode` + `ExplorerScreen`):** `useNode` tracks `settledId` so transitioning node IDs report `loading: true` without 1-frame stale null races, enabling `ExplorerScreen` to recover back to `rootNode.id` automatically whenever `!rootLoading && !nodeLoading && currentNode === null`.
   - **Dark Boot & Production Guards (`app.json`, `_layout.tsx`, `dev-gallery.tsx`):** `app.json` locks `userInterfaceStyle: "dark"` with `#04050A` root/splash/adaptiveIcon background colors, root `_layout.tsx` wraps `<Stack>` in an Obsidian `DarkTheme` (`ThemeProvider`) + `#04050A` view + `<StatusBar style="light" />`, `(tabs)/_layout.tsx` sets `sceneStyle: { backgroundColor: '#04050A' }`, and `dev-gallery.tsx` redirects to `/(tabs)` when `!__DEV__`.
